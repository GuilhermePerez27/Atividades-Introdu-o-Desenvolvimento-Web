#Atividade 02
Utilizando a página HTML desenvolvida na atividade anterior (pode aumentar o código HTML), adicione estilização com CSS. Identifique o html com index.html e o css com style.css ou um nome que não gere dúvidas. Irei corrigir apenas um html/css, mas isso não impede de vocês fazer outros, só preciso que todos os requisitos estejam no principal.

1. Aplicação do CSS (10)
Fazer a ligação corretamente no HTML, fica a sua escolha utilizar inline, 

internal   ou external  stylesheets

2. Estilização básica (40)

Aplicar no mínimo:
Cor de fundo
Cor do texto diferente de preto nos títulos e subtítulos
Trocar a fonte de algum elemento no html (font-family do Google Fonts)
Modificar tamanho e alinhamento de texto
Utilizar mais alguma das estilizações de texto ensinadas em aula

3. Seletores (20)

Utilizar:
seletor de tag
seletor de classe
seletor de id
alguma outra forma de agrupamento de tag que ensinei em aula

4. Box Model e Listas (20)

Aplicar:
As 3 estilizações ensinadas de Box Model
Utilizar no mínimo duas propriedades relacionadas a borda
Estilização de lista conforme ensinado em aula

5. Organização (10)
HTML e CSS organizado e indentado
Comentários (CSS) explicando partes do código 

💡 Extra (Opcional)
Adicionar efeito hover em links
Faça outra página html estilizada com css, linkada na página principal
